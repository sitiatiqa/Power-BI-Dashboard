## Project overview

This Power BI dashboard provides a simple analysis of sales performance from 2018 to 2020. It brings together key sales figures and shows how performance varies by time, county, customer, and product.

## Key results

| Metric | Result |
| --- | ---: |
| Total sales | RM25,661,209 |
| Quantity sold | 21,078 |
| Transactions | 10,889 |
| Total profit | RM8,343,893 |
| Profit margin | 32.5% |

The dashboard also includes a profit trend, a county sales breakdown, customer and product rankings, a geographic profit map, and filters for year and quarter.

## Tools used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## Note on interpretation

The 2020 sheet contains fewer transactions than the 2018 and 2019 sheets. Annual totals should therefore be compared with the difference in data coverage in mind.
